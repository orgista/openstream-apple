# Dolby badge artwork

Drop the owner-supplied official, transparent badge artwork in this folder:

- `dolby-vision.pdf` or `dolby-vision.png`
- `dolby-atmos.pdf` or `dolby-atmos.png`
- `dolby-audio.pdf` or `dolby-audio.png`

The app uses these files as template images. Do not replace them with text or a hand-drawn approximation of the Dolby logos.
